<TagList tags={frontmatter.tags} />
<AttributionList contributors={frontmatter.contributors} />

> 🔑 **Key Takeaway**: DNS hijacks redirect users to attacker infrastructure. Lock
> registrar controls, restore authoritative records, force cache abandonment, and verify
> resolution from multiple resolvers.

## Identification

### Symptoms

<Checklist id="symptoms">
- [ ] Domain pointing to wrong IP
- [ ] Users redirected to malicious site
- [ ] SSL certificate errors (attacker using different cert)
</Checklist>

### Confirm DNS Hijack

```
dig yourdomain.com
 # Compare output to expected IP
```

## Immediate Actions

<Checklist id="immediate-actions">
1. [ ] Regain access to DNS provider account
2. [ ] Enable 2FA if not already enabled
3. [ ] Point DNS to known good infrastructure or maintenance page
4. [ ] Enable DNS lock / registrar lock
</Checklist>

## Prevention

<Checklist id="prevention">
- [ ] Enable registrar lock
- [ ] Use DNSSEC
- [ ] Enable 2FA on DNS provider
- [ ] Limit DNS admin access
- [ ] Monitor DNS records for changes
</Checklist>
