# Security Map

<TagList tags={frontmatter.tags} />
<AttributionList contributors={frontmatter.contributors} />

> 🔑 **Key Takeaway**: Assess controls, not threats. The map is an incomplete, curated graph of SEAL guidance.
> Local ratings never leave this browser.

The Security Map is a way to walk SEAL Frameworks as a graph: what can be compromised, which people and systems
create the exposure, how failure happens, which controls reduce or detect it, and where the implementation page lives.

It replaces the earlier radial Attack Surface Overview. Old threat-level Gap / In Progress / Secured marks are not
security evidence and are not migrated into control assessments.

Start from a domain or a saved entry point. Search and filters stay local. Shareable URLs may include focus, domain,
and view. They never include assessment state.

<SecurityMap />

## How to read the map

- **Assets** are things whose confidentiality, integrity, availability, authenticity, or control matters.
- **Components** are the people, devices, accounts, pipelines, and services in play.
- **Attack surfaces** are specific workflows or trust boundaries, not whole domains.
- **Threats** are adversarial actions or failure modes. They are not assessment items.
- **Controls** are the only things you rate. Not assessed is the default and stays visually neutral.
- **Responses** are containment and recovery procedures.
- **Guidance** nodes open the matching Frameworks page.

The graph canvas is a visual neighborhood. The list is the primary keyboard and screen-reader interface and supports
the same tasks.

## Local assessment

Assessment files are versioned JSON stored under `seal-security-map-assessment:v1`. Import replaces the current
assessment after a preview. Treat exports as sensitive: they can reveal missing controls.
